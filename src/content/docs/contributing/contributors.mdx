The AnyPS5 project develops through independent open-source contributions. Every feature, library stub, instruction test, and documentation fix comes from community members submitting code and test reports.

## Community contributions

The project tracks contributions through Git history and merged pull requests. The table below lists contributors ordered by merged pull request count, along with their primary focus areas. Email addresses are omitted to preserve privacy, and automated bot accounts are excluded.

## Contributing to AnyPS5

If you want to contribute, review the [contributor workflow](/AnyWiki/contributing/workflow/) and [pull request checklist](/AnyWiki/contributing/pr-checklist/) to get started. Pull requests that expand hardware coverage, fix runtime bugs, or implement missing system exports are welcome.
