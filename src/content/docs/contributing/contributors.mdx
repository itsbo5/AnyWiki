AnyPS5 is developed by a distributed community of open-source engineers, reverse engineers, and title testers. Every subsystem, instruction decoder, library export, and test suite represents independent contributions submitted to the repository.

## Project leadership and community contributors

The directory below includes all 857 contributors mapped across the 16,000+ commits and merged pull requests of AnyPS5. The list is sorted by total verified contributions (direct commits plus merged pull requests). Automated bots are excluded, and email addresses are omitted to preserve privacy.

## Contributing to AnyPS5

New contributors are encouraged to submit bug reports, instruction measurements, and library stubs. Review the [contributor workflow](/AnyWiki/contributing/workflow/) and [pull request checklist](/AnyWiki/contributing/pr-checklist/) to begin contributing.
