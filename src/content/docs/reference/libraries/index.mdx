import data from '../../../../data/libraries.json';

AnyPS5 provides native reimplementations and export declarations for 368 system PRX libraries. When a converted executable runs, the host dynamic linker resolves imported symbols directly against these libraries.

## Implementation summary

The project tracks implementation coverage across known function exports:

- **Total declared libraries**: {data.summary.libraryCount}
- **Total declared functions**: {data.summary.total}
- **Implemented functions**: {data.summary.implemented} ({((data.summary.implemented / data.summary.total) * 100).toFixed(1)}%)
- **Inert functions (silent stubs)**: {data.summary.inert} ({((data.summary.inert / data.summary.total) * 100).toFixed(1)}%)
- **Unimplemented stubs**: {data.summary.stub} ({((data.summary.stub / data.summary.total) * 100).toFixed(1)}%)
- **Effective coverage**: {data.summary.percent}% (implemented plus inert functions)

For details on the function states and NID hashing specification, refer to the [library model guide](/AnyWiki/reference/library-model/).
