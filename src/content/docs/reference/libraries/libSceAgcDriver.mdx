The `libSceAgcDriver` library provides the primary graphics hardware interface for PlayStation 5 titles, handling command buffer submission, GPU memory synchronization, register state management, and compute dispatch.

## Subsystem overview

PlayStation 5 titles communicate with the GPU through the Autonomous Graphics Controller (AGC) driver. In AnyPS5, `libSceAgcDriver` translates hardware command packets directly into Vulkan 1.3 API calls:

- **Host dynamic library**: Built as `libs/libSceAgcDriver.prx`.
- **Command submission**: Translates draw and dispatch packets into Vulkan secondary command buffers submitted to graphics and compute queues.
- **Memory synchronization**: Reinterprets `MEM_SEMAPHORE` wait and signal operations as Vulkan timeline semaphores and pipeline barriers.
- **Shader execution**: Directs embedded RDNA2 shader bytecode to the shader recompiler to produce SPIR-V pipelines.

## Known limitations and debt

Technical debt items are documented in `docs/dev/debt/libSceAgcDriver.md` in the upstream repository:

- GPU tests require Vulkan validation layers (`VK_LAYER_KHRONOS_validation`) with zero new `VUID-` validation errors compared to the `main` branch.
- Host memory import budgets (`APS5_HOST_IMPORT_MIB`) cap zero-copy CPU-GPU allocations.
- Texture cache eviction cycles are logged every 10 seconds under `APS5_PROFILE_DRAW=1`.
