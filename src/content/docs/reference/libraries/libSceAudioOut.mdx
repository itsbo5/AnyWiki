The `libSceAudioOut` library manages primary audio output ports, PCM sample buffer submission, master volume adjustments, and channel downmixing for PlayStation 5 applications.

## Subsystem overview

PlayStation 5 software submits decoded audio buffers through `libSceAudioOut`. AnyPS5 routes audio streams to host sound devices:

- **Host dynamic library**: Built as `libs/libSceAudioOut.prx`.
- **Audio backend**: Implemented via SDL2 audio streams, outputting 48 kHz 16-bit or 32-bit float PCM audio.
- **Port management**: Translates `sceAudioOutOpen` calls into managed SDL audio queues.
- **Channel downmixing**: Automatically downmixes 7.1 and 5.1 surround configurations to host stereo devices when multi-channel endpoints are unavailable.

## Known limitations and debt

Technical debt entries are tracked in `docs/dev/debt/libSceAudioOut.md` in the upstream repository:

- 3D spatialized audio objects pass through standard channel downmixing matrices.
- Low-latency buffer underflows are handled by duplicating the previous sample frame to prevent audible clicks.
