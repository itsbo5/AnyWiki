The `libScePad` library handles controller input polling, button states, analog stick coordinates, motion sensors, rumble vibration, and touch surface packets for PlayStation 5 game controllers.

## Subsystem overview

PlayStation 5 titles read controller inputs primarily via `scePadReadState`. In AnyPS5, input polling maps to host input subsystems:

- **Host dynamic library**: Built as `libs/libScePad.prx`.
- **Physical controllers**: Enumerates gamepads using SDL2 controller mappings, supporting physical DualSense and compatible USB/Bluetooth devices.
- **Keyboard and mouse mapping**: Translated through `anyps5-input.ini` configuration files.
- **Deterministic testing**: Allows input injection from recorded files using `APS5_PAD_INPUT_FILE`.

## Known limitations and debt

Technical debt entries are tracked in `docs/dev/debt/libScePad.md` in the upstream repository:

- Advanced DualSense haptic feedback and adaptive trigger resistance motors are inert on non-DualSense controllers.
- Multi-user controller assignment maps to sequential SDL gamepad indices.
