The `libSceVideoOut` library controls display output, swapchain buffer acquisition, presentation timing, HDR color space configuration, and vertical synchronization.

## Subsystem overview

PlayStation 5 titles present frames to the display through `libSceVideoOut`. In AnyPS5, presentation calls translate to host window surfaces:

- **Host dynamic library**: Built as `libs/libSceVideoOut.prx`.
- **Swapchain presentation**: Implemented using Vulkan `VkSwapchainKHR` surface queues managed by SDL2 windowing.
- **Flip submission**: Frame pacing and flip synchronization are handled in `sceVideoOutSubmitFlip`, reporting frame counts under `APS5_PROFILE_DRAW=1`.
- **Display format**: Translates PlayStation 5 pixel formats (such as 10-bit HDR and standard 8-bit sRGB) to host surface formats.

## Known limitations and debt

Technical debt entries are tracked in `docs/dev/debt/libSceVideoOut.md` in the upstream repository:

- 120 Hz presentation modes require host displays capable of 120 Hz refresh rates; titles requesting 120 Hz on 60 Hz monitors require fallback adaptation.
- Headless execution on Linux requires an active Xwayland or Weston environment providing DRI3 rendering.
