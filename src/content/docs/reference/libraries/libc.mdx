The `libc` library provides standard C and C++ runtime library functions for PlayStation 5 applications. In AnyPS5, calls to `libc` link against native host C runtime implementations and memory management primitives.

## Subsystem overview

On the PlayStation 5, `libc` provides standard POSIX and C99 functions including string manipulation, memory allocation, mathematical computations, wide character formatting, and file I/O operations.

- **Host dynamic library**: Built as `libs/libc.prx`.
- **Calling convention**: System V AMD64 ABI on Linux; Windows builds use `APS5_VABI` (`__attribute__((sysv_abi))`) to bridge directly from converted PE executables.
- **Memory allocation**: Mapped to host `mimalloc` or operating system memory arenas to match PlayStation 5 heap alignment guarantees.

## Known limitations and debt

Known technical debt and platform discrepancies are cataloged in `docs/dev/debt/libc.md` in the upstream repository:

- Filesystem operations such as `rename` and `remove` follow FreeBSD path normalization semantics, rejecting paths ending in `.` or `..` with `EINVAL`.
- Wide character formatting functions (`num_put`) map to host libc++ vtables.
- Thread-local storage (`__cxa_thread_atexit`) delegates to host runtime destructors.
