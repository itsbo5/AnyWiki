The `libkernel` library provides low-level operating system facilities including memory allocation, thread management, synchronization primitives, event flags, and system clocks.

## Subsystem overview

In PlayStation 5 software, `libkernel` interfaces between user-space code and the operating system kernel. AnyPS5 maps these calls to native host operating system primitives:

- **Host dynamic library**: Built as `libs/libkernel.prx`.
- **Direct memory allocation**: Mapped to host `VirtualAlloc` on Windows or `mmap` with `udmabuf` on Linux.
- **Threading and synchronization**: Pthreads and mutexes map directly to host POSIX threads on Linux and Slim Reader/Writer (SRW) locks and thread pools on Windows.
- **Event queues**: Reimplemented using epoll on Linux and IO Completion Ports (IOCP) on Windows.

## Known limitations and debt

Technical debt entries are tracked in `docs/dev/debt/libkernel.md` in the upstream repository:

- Direct kernel system calls issued from application code must be validated or trapped using `--trap-sdk-syscall-stubs`.
- Signal handling defers delivery during critical sections to prevent host re-entrancy conflicts.
- Thread stack allocation on Linux reuses virtual address space to manage virtual memory limits.
